# Week 2 - Interactive Image Gallery

## Internship Assignment
**Topic:** CSS + Basic JavaScript  
**Assignment:** Interactive Image Gallery

### Requirements Covered
- Show 8 images in a responsive grid.
- Click an image to open it in a larger lightbox view.
- Previous/Next navigation inside the lightbox.
- Close button and Escape-key support.
- Hover animations on image cards.
- JavaScript DOM manipulation.
- JavaScript event handling.
- Responsive design for desktop, tablet and mobile.

## Files
- `index.html` - Main webpage
- `style.css` - Styling, grid layout and animations
- `script.js` - Lightbox and event-handling logic
- `README.md` - Project documentation

## How to Run
1. Download or clone this project.
2. Open `index.html` in Google Chrome, Microsoft Edge, or another browser.
3. Hover over an image to see the animation.
4. Click an image to open the lightbox.
5. Use Previous/Next, keyboard arrow keys, or Escape to control the lightbox.

## Technologies
HTML5, CSS3, JavaScript (DOM + Events)
